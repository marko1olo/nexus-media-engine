## 📖 About

**Nexus Media Engine** is a premium desktop media viewer built for maximum visual experience. It samples the screen border colors in real time and projects reactive ambient light onto your desktop environment. Combined with a precision FFT audio visualizer and zero-latency image rendering, it turns media consumption into an immersive experience.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌈 **Reactive Ambilight** | Real-time screen color sampling projects ambient glow around the player window |
| 🎵 **Audio Spectrum Visualizer** | High-precision FFT frequency analyzer with customizable neon wave rendering |
| ⚡ **Zero-Latency Slideshow** | Hardware-accelerated image decoding for smooth 4K/8K photo slideshows |
| 🎬 **Video Playback** | Multi-format video support with shader-based post-processing |
| 🌙 **Dark UI** | Native dark-mode interface with glassmorphism design system |
| 🔌 **Plugin System** | Extensible renderer and effect plugin architecture |
